## STEP 2 — Database Setup

Create `src/lib/migrations.ts`. Run this on every app start via `useEffect` in `App.tsx`:

```sql
-- Run in order on first launch

CREATE TABLE IF NOT EXISTS transactions (
    id               INTEGER PRIMARY KEY AUTOINCREMENT,
    brand            TEXT NOT NULL,
    platform         TEXT NOT NULL,
    order_id         TEXT NOT NULL,
    order_status     TEXT NOT NULL,
    is_cancelled     INTEGER NOT NULL DEFAULT 0,
    created_at       TEXT NOT NULL,
    sku              TEXT NOT NULL,
    product_name     TEXT,
    variation        TEXT,
    qty              INTEGER NOT NULL DEFAULT 1,
    price_original   REAL,
    price_after_disc REAL,
    gmv_gross        REAL NOT NULL,
    total_payment    REAL,
    warehouse        TEXT,
    import_batch_id  INTEGER
);

CREATE UNIQUE INDEX IF NOT EXISTS idx_unique_tx
ON transactions(platform, order_id, sku);

CREATE TABLE IF NOT EXISTS import_log (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    brand           TEXT NOT NULL,
    platform        TEXT NOT NULL,
    filename        TEXT NOT NULL,
    imported_at     TEXT NOT NULL,
    row_count       INTEGER,
    skipped_count   INTEGER,
    cancelled_count INTEGER,
    source_type     TEXT NOT NULL DEFAULT 'export',
    gmv_mode        TEXT NOT NULL DEFAULT 'gross'
);

CREATE VIEW IF NOT EXISTS daily_summary AS
SELECT
    strftime('%Y', created_at) AS year,
    strftime('%m', created_at) AS month,
    strftime('%d', created_at) AS day,
    brand,
    platform,
    SUM(CASE WHEN is_cancelled=0 THEN qty ELSE 0 END) AS product_sold,
    COUNT(DISTINCT CASE WHEN is_cancelled=0 THEN order_id END) AS total_tx,
    SUM(CASE WHEN is_cancelled=0 THEN gmv_gross ELSE 0 END) AS gmv_gross,
    SUM(CASE WHEN is_cancelled=0 THEN total_payment ELSE 0 END) AS gmv_net,
    ROUND(
        SUM(CASE WHEN is_cancelled=0 THEN gmv_gross ELSE 0 END)
        / NULLIF(COUNT(DISTINCT CASE WHEN is_cancelled=0 THEN order_id END), 0),
    2) AS aov,
    ROUND(
        SUM(CASE WHEN is_cancelled=0 THEN gmv_gross ELSE 0 END)
        / NULLIF(SUM(CASE WHEN is_cancelled=0 THEN qty ELSE 0 END), 0),
    2) AS rpu,
    COUNT(DISTINCT CASE WHEN is_cancelled=1 THEN order_id END) AS cancelled_tx,
    ROUND(
        COUNT(DISTINCT CASE WHEN is_cancelled=1 THEN order_id END) * 100.0
        / NULLIF(COUNT(DISTINCT order_id), 0),
    2) AS cancellation_rate
FROM transactions
GROUP BY year, month, day, brand, platform;
```

## STEP 3 — Import Engine (`src/lib/importer.ts`)

This is the most critical piece of logic. Read all 4 sample xlsx files before implementing.

### Two source types exist:

**Type A — Existing Database Files** (`required/sample-existing-data/`):
- These are historical Google Spreadsheet exports, already cleaned
- Shopee sheet name: `Sheet1`
- Shopee GMV column: `Total Harga Produk`
- TikTok sheet name: `Sheet1`
- All monetary values in **full Rupiah** (e.g. `85000`, `195000`)
- `source_type = 'existing_db'`

**Type B — Fresh Marketplace Exports** (`required/sample-export-marketplace/`):
- These are direct downloads from Shopee/TikTok Seller Center
- Shopee sheet name: `orders` (not Sheet1)
- Shopee GMV column: `Subtotal Pesanan` (renamed from `Total Harga Produk`)
- TikTok: same column names as Type A
- All monetary values in **thousands** (e.g. `85.0` = Rp 85,000) → multiply × 1000
- `source_type = 'export'`

### Column mapping per platform:

**Shopee (both types):**
```
order_id         ← No. Pesanan
order_status     ← Status Pesanan
created_at       ← Waktu Pesanan Dibuat
sku              ← Nomor Referensi SKU
product_name     ← Nama Produk
variation        ← Nama Variasi
qty              ← Jumlah
price_original   ← Harga Awal
price_after_disc ← Harga Setelah Diskon
gmv_gross        ← "Total Harga Produk" (Type A) OR "Subtotal Pesanan" (Type B)
total_payment    ← Total Pembayaran
warehouse        ← Nama Gudang
```

**TikTokShop (both types):**
```
order_id         ← Order ID
order_status     ← Order Status
created_at       ← Created Time
sku              ← Seller SKU
product_name     ← Product Name
variation        ← Variation
qty              ← Quantity
price_original   ← SKU Unit Original Price
gmv_gross        ← SKU Subtotal After Discount
total_payment    ← Order Amount
warehouse        ← Warehouse Name
```

### Detection logic (implement exactly):

```typescript
function detectFileProfile(headers: string[], rows: Record<string, unknown>[]): FileProfile {
  const isShopee = headers.includes('No. Pesanan');
  const isTikTok = headers.includes('Order ID') && headers.includes('Seller SKU');
  
  const isExistingDB = headers.includes('Total Harga Produk'); // Shopee only tell
  const isFreshExport = headers.includes('Subtotal Pesanan');  // Shopee only tell
  
  // Value scale: sample first 20 non-zero GMV values
  const gmvCol = isShopee
    ? (isExistingDB ? 'Total Harga Produk' : 'Subtotal Pesanan')
    : 'SKU Subtotal After Discount';
  const sampleValues = rows
    .slice(0, 20)
    .map(r => Number(r[gmvCol]))
    .filter(v => v > 0);
  const median = calculateMedian(sampleValues);
  const isThousands = median < 1000; // multiply × 1000 if true
  
  return {
    platform: isShopee ? 'shopee' : 'tiktokshop',
    sourceType: isExistingDB ? 'existing_db' : 'export',
    isThousands,
  };
}
```

### Cancelled order detection:
- Shopee: `Status Pesanan` value contains `"Batal"` (case-insensitive, e.g. "Batal", "Dibatalkan oleh Pembeli", "Batal otomatis")
- TikTok: `Order Status` === `"Dibatalkan"`
- Set `is_cancelled = 1` — STILL insert the row (needed for cancellation rate)

### Insert strategy:
- Use `INSERT OR IGNORE INTO transactions (...)` — silently skips duplicates
- Track `inserted_count` vs `total_rows` to compute `skipped_count`
- All monetary values stored as **full Rupiah** — normalization (×1000) happens at import time only, not at display time

### Multi-file (Shopee):
- Accept array of files in one session
- All inserted rows share the same `import_batch_id`
- Log one entry in `import_log` with comma-separated filenames

## STEP 4 — Formatters (`src/lib/formatters.ts`)

```typescript
// Indonesian Rupiah format: Rp 54.545.870 (dot as thousands separator, no decimals)
export function formatRupiah(value: number | null | undefined): string {
  if (value === null || value === undefined || isNaN(value)) return '—';
  return 'Rp ' + Math.round(value).toLocaleString('id-ID');
}

// Percentage: 3.24%
export function formatPercent(value: number | null | undefined): string {
  if (value === null || value === undefined || isNaN(value)) return '—';
  return value.toFixed(2) + '%';
}

// Date: 01 Jun 2026
export function formatDate(dateStr: string): string {
  return format(new Date(dateStr), 'dd MMM yyyy', { locale: id });
}

// Day only for table rows: 01, 02, ... 31
export function formatDay(day: string): string {
  return day.padStart(2, '0');
}
```

## STEP 7 — Custom Hooks

### `src/hooks/useDailySummary.ts`
- Accepts filter params (brand, platform, gmvMode, dateFrom, dateTo)
- Queries `daily_summary` view via `@tauri-apps/plugin-sql`
- Generates full calendar scaffold (all days from dateFrom to dateTo)
- Merges DB results into scaffold (days with no data = null values)
- Returns `{ data: DailySummaryRow[], totals: SummaryTotals, isLoading: boolean }`

### `src/hooks/useImport.ts`
- State machine: `idle → step1 → step2 → step3 → importing → done`
- Calls `importer.ts` functions at each step
- Exposes `{ step, brand, platform, files, mapping, profile, progress, result, goNext, goBack }`

### `src/hooks/useImportHistory.ts`
- Queries `import_log` table
- Exposes `{ history, isLoading, deleteBatch(id: number) }`
